# Королёв Роман Викторович — финальная редакция сайта

Flask + Jinja + SQLAlchemy / SQLite. Включены финальный чек-лист, присланный новый логотип и последние правки плашек. На реальный домен сайт не публиковался.

## Быстрый просмотр

Откройте `index.html` в браузере. Это автономное превью текущих шаблонов со встроенными изображениями. Работают главная, страницы услуг, три направления дел, профиль, квалификация и просмотр документов. Панель управления требует запуска Flask.

Встроенное превью использует переходы по хешу (`hashchange`), без `history.pushState`: это исправляет блокировку переходов в sandbox/srcdoc. Все четыре карточки услуг проверены реальными кликами в обычном файле и во встроенном просмотре.

После правок источников пересоберите превью: `python build_preview.py` (после установки зависимостей). Не публикуйте автономное превью вместо Flask: SEO и серверные страницы подготовлены для приложения.

## Локальный запуск

Python 3.11–3.13. В папке проекта:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py init-admin
python main.py
```

Windows: вместо второй команды `.venv\Scripts\activate`.

`init-admin` создаёт случайный SECRET_KEY в `.env` и запрашивает пароль скрытым вводом. Минимум 16 символов. Готового пароля в комплекте нет. Сайт: http://127.0.0.1:5001. Панель: http://127.0.0.1:5001/admin.

Локальный режим `LOCAL_PREVIEW=1` разрешает работу по HTTP и запрещает индексацию. Для публикации используйте HTTPS и `LOCAL_PREVIEW=0`. Если SECRET_KEY отсутствует или короче 32 символов, запуск намеренно запрещён.

## Редактирование

- `defaults.json`: ФИО, стаж, контакты, начальные тексты и домен.
- `content.json`: услуги, направления дел, клиенты, опыт, партнёры, гарантии и документы.
- `templates/`: шаблоны, `static/css/style.css`: стили, `static/js/site.js`: мобильное меню и галерея.
- `static/brand/logo-approved.webp` и `.png`: последний присланный логотип, подготовленный на прозрачном фоне.
- `static/brand/logo-footer.webp` и `.png`: светлый вариант с приглушённой рубиновой руной «Л» для тёмного подвала.
- `static/img/organizations/`: нормализованные логотипы организаций; пропорции не растянуты. Цветные исходники сохранены отдельно.
- `static/img/documents/`: оригинальные развороты, аттестаты и облегчённые миниатюры. Содержание сканов не перерисовано; выделение фамилии — отдельный слой.
- `source-materials/`: предоставленные исходные изображения, включая новый логотип. Не раздавайте эту папку публично.
- `storage/`: создаваемые при работе база, хеш пароля и пользовательские правки. После сохранения в панели `storage/content.json` имеет приоритет над исходным `content.json`.

В панели доступны основные тексты и контакты, загрузки изображений/документов и JSON-редактор разделов. Для партнёров есть отдельная форма добавления (название, необязательные описание и логотип) и кнопки удаления. Логотипы при загрузке приводятся к единому монохромному полю. Для опыта выравнивание слева; Инкомбанк остаётся центрированным. Лучше использовать оригиналы на прозрачном или белом фоне.

Плашки стажа автоматически показывают число из `experience_years`, отдельно слово «лет» и остаток подписи `experience_caption`, начинающейся с «лет ». На главной и в профиле они центрированы относительно портрета.

Для выделения фамилии у документа используется `highlights: [[x,y,width,height]]`: проценты от полного разворота. При замене скана координаты нужно пересчитать. Удаление документа/партнёра убирает публикацию, но не удаляет автоматически исходный файл и резервные копии.

## Перед публикацией

1. Подтвердите тексты, права на материалы и допустимость открытой публикации реквизитов и персональных сведений на сканах. Юридическая экспертиза текстов и проверка актуальности квалификации не проводились.
2. Выберите основной домен www / без www. В настройках указан https://korolev.expert. Выпуск сертификата и покрытие имён нужно проверить на реальном хостинге.
3. Создайте собственные секреты и пароль; установите `LOCAL_PREVIEW=0` и HTTPS.
4. Запускайте Gunicorn за HTTPS reverse proxy, от непривилегированного пользователя:

```bash
gunicorn -c gunicorn.conf.py wsgi:app
```

5. Не открывайте корень приложения как статическую папку. `.env`, `storage/`, SQLite, хеши паролей и исходные материалы не должны быть публичными.
6. Резервируйте `storage/` и `static/img/uploads/`. Для записи JSON рекомендован один процесс записи. После выпуска проверьте sitemap, robots, canonical и редиректы www/non-www.
7. Dockerfile/compose включены, но Docker в этой среде не запускался. Для Docker подготовьте production `.env`; при первоначальной настройке можно временно задать ADMIN_PASSWORD от 16 символов, затем удалить переменную. Хеш остаётся в постоянном томе. HTTPS/DNS настраиваются отдельно.

Формы обратной связи и приёма заявок нет; `/contact` возвращает 410. Доступны прямые телефон и почта. Ссылки на Telegram/WhatsApp появляются только после заполнения реальных данных в панели. Отсутствие формы не заменяет проверку обязанностей владельца по работе с почтой и техническими журналами.
